## من الطلب إلى الاستجابة. بأقل جهد ممكن.

لا ينبغي أن يستهلك الإطار وقتك في أعمال لا يحتاج إليها تطبيقك. صُمّم **Barq** ليمنحك أساسًا سريعًا وخفيفًا لبناء خدمات HTTP وواجهات API وتطبيقات WebSocket باستخدام **Bun و Node.js**.

يستخدم Barq خادم Bun الأصلي ووحدات HTTP الأصلية في Node.js، وموجّهًا يعتمد على بنية Trie لمطابقة المسارات بكفاءة، مع التركيز على تقليل العمل الإضافي في مسار الطلب.

**النتيجة التي نسعى إليها: أداء عالٍ، وشيفرة واضحة، وحرية أكبر في بناء تطبيقك.**

## بداية بسيطة. ونتائج ملموسة.

أنشئ تطبيقًا، وسجّل مسارًا، وأعد استجابة JSON. هذا كل ما تحتاج إليه لفهم الفكرة الأساسية:

```ts
import { App, json } from "@barqel/barq";

const app = new App();

app.get("/users/:id", (ctx) => {
  return json({ id: ctx.params.id });
});

const server = app.listen(3000);

console.log(`Server running at http://localhost:${server.port}`);
```

شغّل التطبيق، ثم أرسل طلبًا إلى:

`http://localhost:3000/users/42`

ستكون الاستجابة المتوقعة:

```json
{
  "id": "42"
}
```

ما الذي يحدث هنا؟

- `App` ينشئ تطبيق Barq.
- `app.get()` يربط طلبات `GET` بالمسار المحدد.
- `ctx.params.id` يقرأ قيمة `id` من عنوان الطلب.
- `json()` يعيد البيانات بصيغة JSON.
- `app.listen(3000)` يشغّل الخادم على المنفذ `3000`.

لا تحتاج إلى إعداد منظومة كبيرة لتبدأ. ابدأ بمسار واحد، ثم أضف بقية وظائف تطبيقك خطوة بخطوة.

## كل جزء من الثانية يستحق الاهتمام.

السرعة ليست إضافة تأتي بعد اكتمال الإطار؛ بل هي أحد الاعتبارات الأساسية في تصميم Barq.

يركز الإطار على خادم Bun الأصلي، ووحدات HTTP في Node.js، والتوجيه باستخدام Trie، وتقليل العمل الإضافي في مسار الطلب. والهدف هو إتاحة تنفيذ سريع دون فرض تعقيد غير ضروري على شيفرتك.

لكن الأداء الحقيقي يعتمد أيضًا على ما يفعله التطبيق، وحجم الاستجابات، وطبيعة الحمل، وبيئة التشغيل. لذلك ينبغي تقييم Barq من خلال اختبارات قابلة للتكرار تقارن الحالات نفسها وتعرض النتائج بوضوح.

## أساس قوي. وحرية كاملة في البناء.

ليس كل مشروع بحاجة إلى إطار ضخم أو مجموعة أدوات مفروضة عليه. أحيانًا يكون أفضل ما تحتاج إليه هو أساس واضح وسريع يمكنك البناء فوقه بالطريقة التي تناسبك.

يوفر Barq هذا الأساس لتطبيقات HTTP وواجهات API وWebSocket باستخدام **Bun و Node.js**، دون اعتماديات تشغيل خارجية.

**ابدأ اليوم، واكتشف بنفسك كيف يناسب Barq مشروعك.**

انتقل إلى [دليل البداية السريعة](/ar/getting-started/quickstart/) لبناء أول تطبيق لك.
