# التثبيت

ابدأ باستخدام **Barq** خلال دقائق. اختر Bun أو Node.js لتشغيل HTTP، وثبّت الحزمة، وأنشئ ملف JavaScript لتشغيل تطبيقك.

سنجهّز المشروع خطوة بخطوة، من التحقق من المتطلبات حتى تشغيل الخادم محليًا.

## المتطلبات

قبل تثبيت Barq، تأكد من توفر ما يلي:

- **Node.js بإصدار 18 أو أحدث** لتطبيقات HTTP، أو **[Bun](https://bun.sh/) بإصدار 1.1 أو أحدث**. يدعم محوّل Node.js بروتوكول HTTP؛ أما WebSocket الأصلي وخيارات الخادم الخاصة بـBun فتتطلب Bun.
- **JavaScript أو TypeScript.** تستخدم الأمثلة التالية JavaScript لتعمل مباشرةً عبر `node`. ويستطيع Bun تشغيل ملفات TypeScript دون خطوة ترجمة منفصلة. لتشغيل TypeScript على Node.js، ترجم الملفات إلى JavaScript أولًا ثم شغّل الناتج باستخدام `node`.

تحقق من بيئة التشغيل التي تريد استخدامها:

```sh
node --version
bun --version
```

ثبّت Node.js من [nodejs.org](https://nodejs.org/) أو Bun من [الموقع الرسمي](https://bun.sh/).

## تثبيت Barq

أفضل وأسرع طريقة للبدء هي إنشاء مجلد جديد، تهيئته، ثم تثبيت أحدث إصدار من الحزمة دفعة واحدة:

<Tabs syncKey="package-manager">
<TabItem label="Bun">

```sh
mkdir app-barq && cd app-barq
bun init -y
bun add @barqel/barq@latest
```

</TabItem>
<TabItem label="npm">

```sh
mkdir app-barq && cd app-barq
npm init -y
npm install @barqel/barq@latest
```

</TabItem>
</Tabs>

يضيف هذا الأمر حزمة `@barqel/barq` إلى تبعيات المشروع وتصبح جاهزة للاستيراد.
أما في المشروع القائم، فاستخدم `npm install @barqel/barq` أو `bun add @barqel/barq`.

## استيراد Barq

Barq حزمة من نوع ECMAScript Module (ESM)، والاستيراد الواحد يغطّي بيئتي التشغيل معًا. الجذر يوجّه تلقائيًا إلى خادم HTTP الذي تشغّله فعلًا: خادم Bun الأصلي مع Bun، ومحوّل Node.js مع Node.js:

```js
import { App, json } from "@barqel/barq";
```

بقية واجهات HTTP واحدة في بيئتي التشغيل. تتطلب مسارات WebSocket وخيارات TLS للخادم وتشغيل العمال المتعددين وحدود الخادم الخاصة بـBun استخدام Bun؛ راجع [إعداد الخادم](/ar/docs/runtime/server) و[اتصالات WebSocket](/ar/docs/runtime/websockets).

لا تتطلب Barq حزم تشغيل خارجية. ويمكنك استخدام npm أو Bun لإدارة الحزم؛ أما الميزات المتاحة فتتحدد ببيئة التشغيل المختارة.

## إنشاء نقطة الدخول

نقطة الدخول هي الملف الذي يبدأ منه تشغيل تطبيقك. لإنشاء تطبيق JavaScript، أضف الملف التالي:

```text
src/
└── index.js
```

أضف إليه كود الخادم. وإذا كنت تستخدم npm وNode.js، فعّل ESM في المشروع:

```sh
npm pkg set type=module
```

اتبع [البداية السريعة](/ar/docs/getting-started/quickstart) للاطلاع على مثال كامل. شغّل ملف JavaScript نفسه باستخدام بيئة التشغيل التي تختارها:

<Tabs syncKey="runtime">
<TabItem label="Node.js">

```sh
node src/index.js
```

</TabItem>
<TabItem label="Bun">

```sh
bun run src/index.js
```

</TabItem>
</Tabs>

يشغّل Node.js ملفات JavaScript مباشرةً؛ لا تحتاج في هذا الدليل إلى `tsx` أو محمّل TypeScript. وإذا كان الخادم يستمع إلى منفذ محدد، فأرسل الطلبات إلى عنوانه المحلي والمنفذ الذي اخترته.

## إعداد منفذ الخادم

يحدد المنفذ (Port) المكان الذي يستقبل عليه الخادم اتصالات HTTP. على سبيل المثال، عند استخدام المنفذ `3000`، يكون العنوان المحلي المعتاد:

```text
http://localhost:3000
```

إذا لم تحدد منفذًا في `listen()` أو في `AppOptions.port`، فقد يختار Bun منفذًا متاحًا تلقائيًا. للحصول على عنوان محلي ثابت، حدّد المنفذ صراحةً أو اقرأه من متغير البيئة `PORT`.

لذلك، عند تشغيل خدمة محلية، يمكنك تحديد المنفذ صراحةً، أو قراءة قيمته من متغير البيئة `PORT` مع استخدام `3000` كقيمة افتراضية:

```js
const port = Number(process.env.PORT ?? 3000);
```

يعمل التعبير على النحو التالي:

1. يقرأ `process.env.PORT` إذا كان متغير البيئة `PORT` محددًا.
2. يستخدم `3000` إذا لم يكن المتغير موجودًا.
3. يحوّل القيمة الناتجة إلى رقم باستخدام `Number()`.

يجهّز هذا التعبير قيمة المنفذ فقط؛ مرّرها إلى `new App({ port })` أو `app.listen(port)`. وتأكد من أن قيمة `PORT` رقم صالح وأن المنفذ متاح. تعمل `process.env` في Node.js وBun.

## ماذا بعد التثبيت؟

بعد تثبيت Barq وتجهيز نقطة الدخول، يمكنك الانتقال إلى الموضوع الذي تحتاج إليه:

- [البداية السريعة](/ar/docs/getting-started/quickstart) — أنشئ أول تطبيق وتعرّف على طريقة تشغيله.
- [أنماط المسارات](/ar/docs/basics/routing) — تعرّف على كيفية استقبال الطلبات وتحديد المسار الذي يعالج كل طلب.
- [سياق الطلب ومساعداته](/ar/docs/basics/context) — افهم الأدوات المتاحة للتعامل مع الطلب والاستجابة.
- [مرجع الواجهة البرمجية](/ar/docs/api-reference) — راجع الصادرات العامة والواجهات المتاحة في Barq.

إذا كنت تستخدم Barq للمرة الأولى، فابدأ بـ **البداية السريعة**؛ فهي الطريق الأقصر للانتقال من تثبيت الحزمة إلى تشغيل أول تطبيق.
