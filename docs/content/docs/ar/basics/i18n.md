# تعدد اللغات (i18n)

توفر إضافة `@barqel/barq-i18n` نظاماً سريعاً لتعدد اللغات للـ APIs، مع مفاوضة ترويسة `Accept-Language` بناءً على أوزان الجودة (q-factors)، ودعم المفاتيح المتداخلة والمتغيرات بدون أي اعتماديات خارجية.

## التثبيت

```bash
bun add @barqel/barq-i18n
```

## البداية السريعة

```ts
import { App, json } from "@barqel/barq";
import { i18nPlugin } from "@barqel/barq-i18n";

const app = new App();

app.plugin(
  i18nPlugin({
    defaultLocale: "en",
    locales: ["en", "ar", "fr"],
    translations: {
      en: {
        welcome: "Welcome, {name}!",
        errors: { notFound: "Item not found" },
      },
      ar: {
        welcome: "مرحباً، {name}!",
        errors: { notFound: "العنصر غير موجود" },
      },
    },
  })
);

app.get("/hello", (ctx) => {
  const t = (ctx as any).t;
  return json({
    locale: ctx.state.locale,
    message: t("welcome", { name: "عادا" }),
    error: t("errors.notFound"),
  });
});

app.listen(3000);
```

## أولويات تحديد لغة الطلب

يتم تحديد لغة العميل تلقائياً بحسب الترتيب التالي:
1. دالة استخراج مخصصة (إن وُجدت)
2. معامل الرابط (`?lang=ar`)
3. الكوكيز (`lang=ar`)
4. ترويسة `Accept-Language` مع حساب أوزان Q
5. اللغة الافتراضية للخدمة
